# Changelog

## 1.3.0

A trackpad swipe covers an armed desk. While the cover is up, a swipe does not change windows. The swipe that moves between windows is included.

The menu has About. About shows the version and the credits. Check for Updates opens the release page in the browser. The program sends no request.

## 1.2.0

While the desk is armed, Control-Command-Q shows the cover. After Disarm, that command locks the screen. A click on Lock Screen or Shut Down still reaches macOS.

## 1.1.0

When Accessibility is off, the program shows a setup notice. The notice can open Privacy and Security.

## 1.0.0

The first public build keeps a Mac awake. An armed desk covers every display after a physical touch.
